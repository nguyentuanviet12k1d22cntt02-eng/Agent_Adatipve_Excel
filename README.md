# Agent_Adatipve_Excel

Hệ thống Gia Sư AI Thực Hành Microsoft Excel Thích Ứng (Adaptive AI Excel Tutor) xây dựng trên nền tảng **Model Context Protocol (MCP 2.x)** và **Thuyết Tải Nhận Thức (Cognitive Load Theory)**.

## Tính năng chính
- **Giám sát thời gian thực (Realtime Excel Monitor)**: Tự động bắt dính cửa sổ Excel, vị trí ô, vùng chọn, công thức và giá trị qua dynamic COM.
- **Theo dõi thần kinh cơ học (Mouse Telemetry)**: Đo lường tốc độ chuột, phát hiện trạng thái ngập ngừng/bối rối của học viên.
- **Hỗ trợ sư phạm 3 cấp độ (Scaffolding)**:
  - Cấp 1: Gợi ý định hướng tư duy.
  - Cấp 2: Chỉ dẫn công cụ/thao tác cụ thể.
  - Cấp 3: Khung đỏ trực quan bám sát mục tiêu trên màn hình.
- **Teachable Agent (Phản biện sư phạm)**: Học viên giải thích lại kiến thức để củng cố ghi nhớ dài hạn (LLM chấm điểm tương tác).
